# Reproduce the v0.2.14 re-audit

Use commit `c8073ddd7d639b0f0c68b64f6d319a711c5c2bea` plus this audit directory. Run scripts on a separate copy when preserving the original evidence: scripts write JSON and screenshots beside themselves.

## Baseline

```sh
node tools/build.js
npm test
npm install --prefix /tmp/agc-audit-runtime jsdom@26.1.0
NODE_PATH=/tmp/agc-audit-runtime/node_modules npm run test:ui
python audits/2026-11-19-v0.2.14/evidence/verify_release.py
```

`results/baseline.json` summarizes the engine run observed in this audit; `results/ui-tests.txt` is the captured full UI output. Engine and data files match v0.2.13, apart from `APP_VERSION`.

## Fresh campaigns and ordered movement observation

```sh
node audits/2026-11-19-v0.2.14-reaudit/evidence/campaign/sweep.js . 970000 64 fresh
AGC_OPTION_GRID=1 AGC_POLICIES=coast node audits/2026-11-19-v0.2.14-reaudit/evidence/campaign/sweep.js . 972000 64 options
node audits/2026-11-19-v0.2.14-reaudit/evidence/map-audit.js .
```

The fresh and option harnesses are copied from the established v0.2.13 audit harness and use new seeds. They check the printed scoring components independently of the tally implementation. The map harness is new: it observes completed procedure handlers, compares movement history with actual transitions, and compares every resulting full state with a separate direct-engine runtime. It never changes the selected move, game dice or rules. All four grouping/AI-notice configurations are included.

`map-audit.json` records 28 actions whose internal movement steps are missing from the map report. Passing gameplay equivalence does **not** assert map-history fidelity. The before/after JSON files are importable app saves, generated by these tests.

## Browser

The run used Playwright with Chromium 153.0.8010.0, supplied by `@sparticuz/chromium`. The normal Playwright browser download was unavailable in this environment; no app workaround was needed. The scripts expect Playwright and the Chromium package on Node's module path.

```sh
npm install --prefix /tmp/agc-audit-runtime @sparticuz/chromium@153.0.0 playwright
NODE_PATH=/tmp/agc-audit-runtime/node_modules node audits/2026-11-19-v0.2.14-reaudit/evidence/browser/map-layout.js .
NODE_PATH=/tmp/agc-audit-runtime/node_modules node audits/2026-11-19-v0.2.14-reaudit/evidence/browser/findings.js .
NODE_PATH=/tmp/agc-audit-runtime/node_modules node audits/2026-11-19-v0.2.14-reaudit/evidence/browser/campaigns.js .
```

`campaigns.js` starts each side through setup and uses actual visible buttons, checkboxes, selectors and ship choices. It compares the entire JSON state after every decision, and uses actual Undo, reload and Map controls. `AGC_SEATS=BR` resumes just that browser case, reusing an already completed U.S. evidence file. Browser startup/serialization/selector issues in the harness were corrected before the final two completed runs; they were not app findings.

`findings.js` verifies the empty port dialogs, replays the omitted-move fixture through assignment controls, checks map privacy, and demonstrates the optional Back-navigation improvement. `map-layout.js` measures SVG endpoints and HTML rectangles, then saves screenshots for visual review. Its geometric results are screening evidence; the report describes the examples that were visually confirmed.

At 1024 px, use `crowded.json`, scroll to Tracks, and compare `document.documentElement.scrollWidth` with `innerWidth` to reproduce A04. `browser/overflow.json` lists the actual overflowing elements and coordinates.
